# Road Crash Dashboard

> An interactive dashboard for exploring Australian road crash data.

![Type](https://img.shields.io/badge/type-university%20project-blue)

---

## Overview

An interactive dashboard for exploring Australian road crash data. This repository describes the project at a high level. The source code is not public (see below).

## The Problem

Raw crash data is hard to read as a table. People need a way to filter it and see trends over time to understand patterns.

## Why I Built It

Built to practise data visualisation and create something a viewer can explore themselves instead of looking at a fixed chart.

## Key Features

- Interactive line charts of crash data
- Filters that change what the charts show
- Dark and light theme built on CSS custom properties

## How It Works

1. Crash data is loaded and prepared in the browser
2. D3 binds the data to chart elements
3. Filters update the data and redraw the charts
4. CSS variables switch the theme between dark and light

## What I Learned

- Binding data to the DOM with D3
- Designing charts that are easy to read
- Building a theme system with CSS variables
